## Decision and scientific scope

Potentially useful as active inference of **synthetic cache replacement automata under
charged, noisy observations**. It is not evidence of recovering a real processor's policy.
The observation-to-policy abstraction is a real research direction: the authors of
[CacheQuery](https://arxiv.org/abs/1912.09770) infer deterministic policies from silicon timing
measurements using automata learning. This task starts after that hardware abstraction and
implements its own policy tables and independent Bernoulli channel flips.

The current PR is **not ready for scientific admission**. Its 0.556 reference line is rejected:
`TASK_CARD.yaml` and `reference_lstar_family.py` explicitly describe a deliberately omitted
permutation-policy inference family. The supplied `ladder.jsonl` has eight reference records
at shift-0 0.5556/0.5000 and eight `headroom` records at 0.7778/0.7500, with no recorded false
claims in either eight-shift group. Those are builder observations, not independently replayed
current-source or sandbox evidence. Restoring a known successful ability is required before
setting a threshold; calling that omission “headroom” does not justify a lower reference.

The 32-state L* claim cap is a separate question. The supplied `cap_big` group records three
false claims over eight shifts, and `all_parts` records five; merely lifting the cap would not
establish a stronger valid reference. The bounded repair adds a standalone
`reference_permutation_augmented.py` candidate using public callbacks only, with the existing
permutation fit before L*. It preserves the cap as an explicitly provisional false-positive
control. Completeness and its measured admission threshold remain open. The permutation fit
assumes W consecutive misses cycle through the resident ways; outside that family it returns
no fit and falls back to L*. It is not a universal automaton-learning solution.

## Concrete engineering findings and repairs

1. **Cross-world state:** `_evaluate_world` previously reused CandidateProxy module globals,
   imported state and tmpfs through all 18 worlds, including development to heldout. It now
   calls a supported `reset_session()` at each world boundary, outside scientific scoring's
   exception handler. Within-world `run` callbacks share their process and retain their budget.
2. **Caught malformed query still earns credit:** before the repair, a candidate calling
   `run([])`, catching `ValueError`, then returning `abstain=True` had `valid=1`, feasibility 1,
   and all five randomised worlds earned mechanism 1 plus correct-refusal credit. That violates
   the stated invalid-trace contract. Trace validation now sets a lasting violation before
   raising; catching it cannot restore a valid scientific result.
3. **Wrapper infrastructure failure:** the old wrapper caught every error, wrote sentinel
   metrics and returned success, without private sidecars. It now uses the shared standard-
   library launcher, explicit metadata timeout 360 s, and fail-closed/private-sidecar behavior.
4. **Missing machine-readable reporting/admission contract:** split ratios lacked numeric
   denominators; there was no shortcut contract. Counts now include all planned worlds, and
   the four axes declare their estimands. FDR uses false policy claims / valid non-abstaining
   policy claims; the old per-world rate remains `false_claim_world_rate`. Empty claims report
   zero with explicit `policy_claim_count=0`, and coverage remains separately required.
   Reference and probe declarations deliberately use
   `expected_score: null`; runtime/shortcut checks remain incomplete until actual measurements.

The old reference is retained as an omission probe, not erased or retrospectively relabelled.
Task and registry prose explicitly marks the new reference and current admission status as hold.

## Data and evidence provenance

All worlds are synthetic. Five written-out permutation tables reproduce the supplied generator:
`dev-03 = random_permutation_policy(4,101)`, `dev-04 = lip_like(4,2,6)`,
`dev-06 = lip_like(6,0,1)`, `held-02 = random_permutation_policy(4,606)`, and
`held-03 = lip_like(6,0,9)`. A bounded fixture compares all hit/miss tables and reset states,
not just the number of states. Other worlds directly instantiate explicit textbook or modified
policy classes. Runtime seeds key a hash of the trace plus that trace's repeat number, providing
order-independent reproducible noisy runs. Seed shifts redraw observations of the **same 18
policies**; they do not constitute new mechanisms or independent hardware sources.

The checked-in builder JSONL records carry scores, shifts and aggregate/per-world usage, but
no current task/runtime hashes, trusted sandbox receipts, complete planned grid or per-world
valid flag in the ladder rows. They remain construction context. A current source-bound replay
must retain missing/invalid cells and measure complete-reference and omission probes separately.
The claimed 52-strategy shortcut screen also does not meet the contribution guide's expectation
of hundreds or thousands of fixed low-dimensional alternatives; plan and run a broader finite
grid only in the next authorized scientific stage.

The score is exact automaton equivalence per world, averaged over nine deterministic development
worlds and normalized against three refusal worlds. It therefore has coarse 1/9 increments,
not a smooth per-world objective. It is more than a binary overall score, but adequate headroom
and useful iterative signal require empirical calibration. Top-level `valid=1` still means at
least one development world is valid; difficulty needs full feasibility and all 18 rows valid.

The prose “same reset state” also needs care for randomised policies: `_Bimodal.reset` itself
draws a random insertion choice. The resident block-to-way mapping is fixed while metadata can
be stochastic. The public reset description now states that distinction, without
claiming physically identical metadata in every randomised run or reconstructing a real CPU's
warm-up circuit. No hidden world is relabelled or generator distribution changed.

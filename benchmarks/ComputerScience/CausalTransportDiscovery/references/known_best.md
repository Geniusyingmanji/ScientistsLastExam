# Construction evidence, not a certified best score

## Reference method

The truth-blind witness surveys recruitment enrichments, uses cheap source
subjects for concordant cells, and obtains paid paired biomarkers and outcomes
from useful bridge sites for discordant curves. Bounded continuous least squares
fits the public Bernstein family. Uncertainty uses conservative Bernoulli
variance at most1/4. This is an attainable method, not a claim of optimality.

## Baselines

The fixed policy uses cheap source cohorts and every bridge site at every dose,
spending all12000 units. `fixed_full_factorial` spends the full budget on bridges
without a pilot survey. Random recruitment uses an independent fixed RNG and
the same estimator. Source-only, unsafe extrapolation, zero-prior, full-bounds
and all-abstention policies expose different failure modes.

## Scientific ablations

Source-only observations cannot identify either discordant curve. A paired-world
test pins that statement with identical observations. Access-limited pairs
have identical metadata and every available tool output but differing target
effects. Complete-outcome confirmation supplies genuinely new observations
after commitment, using the same synthetic family.

## Shortcut probes and rejected construction

The first rotating-site fixed control was weaker than a full factorial and
paid for surveys it ignored. Review replaced it with stronger controls. A
symmetric fixed multiset of site enrichments was replaced with independently
variable enrichments. The optimized fixed policy can still outperform the
adaptive witness; this is retained rather than edited away. Exact generator
modifier masks are easy for a fixed regression program and are now explicitly
diagnostic, not the scientific difficulty headline.

Zero priors can recover negligible modifiers and claim full curve coverage
without data. Public access metadata suffices for correct unsupported-cell
refusal. Neither is evidence of scientific discovery; quantitative error,
interval width and calibration, and the joint precision criterion must accompany
these metrics.

## Frontier draws

No frontier model has been evaluated on this new contract. No hard-tier or
default-suite admission is justified by construction controls.

## Construction checks

`tests/test_causal_transport_discovery.py` checks bounded response probabilities,
source/target observational equivalence, paired biomarker sampling, matched
budgets, preserved partial identification, fresh confirmation, finite result
serialization, malformed actions and claims, and exact replay.

## Robustness and remaining review

`verification/audit_controls.py` generates source-bound construction results.
Adjacent seeds share nuisance parameters and are not independent model draws.
Independent population/parameter panels, weaker enrichment, site relabeling,
misspecified response functions and real external validation remain necessary
before broader claims. Only source/model hashes recorded in the report define
which contract its observations support.

# GravityInversion — actively survey and infer subsurface density bodies

## Scientific setting

Surface gravity is an integrated external field: many subsurface density distributions can
produce similar observations. A scientifically useful inversion therefore needs both an
informative survey and an interpretable source model, while retaining the ability to say that
the declared source family is unsupported.

Each hidden world is either generated by 1–3 signed, infinite-strike rectangular density
bodies, contains no anomaly, or contains a smooth seven-lobe density field that cannot be
represented by the public at-most-four-body library. You choose horizontal station positions
and observation heights, then return rectangular bodies or explicitly abstain.

Each body row is:

```text
[x_center_m, depth_center_m, width_m, height_m, density_contrast_kg_m3]
```

The benchmark uses the following infinite-strike rectangular-body forward model. For rectangle
edges `x1,x2,z1,z2`, station `x`, observation height `h`, density contrast `rho`, and SI
gravitational constant `G = 6.67430e-11`,

```text
F(a,z) = z atan2(a,z) + (a/2) log(a^2 + z^2)
g_z(x,h) = 2 G rho [F(x2-x,z2+h) - F(x2-x,z1+h)
                    - F(x1-x,z2+h) + F(x1-x,z1+h)] * 1e5  mGal.
```

Depth is positive downward. Fields from multiple bodies add linearly. This equation is public;
hidden information consists of the worlds, noise realizations and evaluator-only surveys.

## Your task

```python
def discover_bodies(profile_bounds_m, depth_bounds_m, measure, budget_units):
    """Return:
      bodies:     array-like with shape (0-4, 5)
      confidence: scalar in [0,1]
      abstain:    bool

    measure(station_x_m, observation_height_m=0.0) returns:
      station_x_m:          selected strictly increasing stations
      observation_height_m: selected height
      gravity_mgal:         noisy vertical gravity observations
      noise_std_mgal:       stated pointwise noise standard deviation
      budget_cost:          charged survey units
    """
```

A survey call contains 4–24 stations within `[0,10000]` m and a height in `[0,1500]` m. Its
cost is `1 + ceil(n_stations/4)`; total cost must not exceed 24. Candidate bodies must lie fully
inside the public profile and `[100,5000]` m depth interval. Public parameter bounds are:

- x center `[0,10000]` m and depth center `[200,4700]` m;
- width `[200,3500]` m and height `[150,1800]` m;
- absolute density contrast `[50,800]` kg/m³.

If `abstain=True`, return an empty body list. Survey errors do not refund budget; catching an
overspend exception cannot make the world valid.

## Evaluation

- `combined_score` measures signed-body support, individual external-field components and mass
  moments on development worlds, normalized so always abstaining is zero.
- observed-data fit, sealed interpolation and outside-profile/high-altitude extrapolation are
  reported separately from mechanism recovery.
- `robustness_score` evaluates held-out topologies, parameters and larger observation noise.
- null and smooth out-of-library worlds report correct refusal, confidence and false discovery.

No pixelwise hidden-density similarity is used. Body matching is permutation invariant and
primarily based on each source's external field plus signed mass, horizontal centroid and depth
centroid. Thus equivalent external-field explanations receive partial credit, while excellent
field fit is not automatically treated as proof of a unique internal geology.

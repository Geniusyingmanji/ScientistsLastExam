目标：理解现象、理解规律、应用规律

用可交互科学环境考察agent从观测中恢复规律和结构，并在新情境中应用。结果与探索过程分别评价，不能用材料齐全度替代科学发现程度。

通用研究 Query 模板

主任务采用有边界的开放研究：给定研究对象、范围与交付要求，由 agent 自主提出子问题、选择实验和建立模型。下列模板用于后续新任务设计；替换双花括号字段后，随任务冻结公开说明、预算和交付接口。现有批次继续使用原题面与评分。

研究 Query 发给 agent；实验环境接收 agent 自主选择的操作。实验控制（初始组成、温度、采样时刻等）与私有世界参数分开：重新制备样本通常改变初态，不重新抽取底层机制。共同核心任务决定评分范围，自主子问题允许未预列但可验证的发现，不能通过缩小自选问题缩小核心评分分母。

统一研究成果与过程记录

产物内容与用途
report.md研究问题、主要发现、解释、局限与未解决问题。
claims.json可逐项核查的陈述、适用范围、数学表示与证据；不要求每层固定提交几条主张。
模型文件及必要状态按各环境公开接口产生预测。三菌与振子采用 model.py / predict(spec)，列顺序由仪器合同指定。
可信过程记录由环境自动保存实验、观测、预算、预测登记、模型版本与时间顺序。由提交工具生成并核验封存清单。
展开 claims.json 通用示例
{
  "research_questions": [
    {
      "id": "q1",
      "question": "自主选择的具体研究问题"
    }
  ],
  "claims": [
    {
      "id": "c1",
      "question_id": "q1",
      "kind": "law",
      "statement": "具体、可检验的科学陈述",
      "scope": {
        "conditions": "成立的条件范围",
        "time_range": "成立的时间范围",
        "interventions": "适用的干预范围"
      },
      "representation": {
        "equations": [],
        "variables_and_units": {},
        "parameters": {}
      },
      "evidence": {
        "supporting_ids": [],
        "contradicting_ids": [],
        "prospective_test_ids": []
      },
      "alternative_explanations": [],
      "uncertainty": "尚未确定的部分",
      "status": "partially_supported",
      "model_version": "对应模型版本"
    }
  ],
  "unresolved_questions": []
}

kind 可取 phenomenon、law、structure、mechanism；不适用的数学表示可以为空。status 是 agent 对证据的判断，最终科学评价由评测器完成，事前预测由可信记录核验。该结构是新交付方案，尚未替换现有 runner 的提交 schema；接入前须验证适配，旧声明与成绩不改。

接口样例、格式检查和文件封存应明确且易用，不提供隐藏科学反馈。默认、方法辅助和定向辅助条件分别冻结与比较，不能将辅助运行的成绩当作无提示结果。

三层能力与独立过程分

能力权重内容
现象理解20%效应、条件与不确定性
理解规律40%结构、形式、定量恢复及可辨识解释
应用规律40%新情境、组合干预与适用范围

过程分：假设形成20%、实验设计30%、证据更新30%、验证复现20%。基于可见行为和可信收据，不读取内部思考；不和结果分混成总分。评分采用连续部分分，未审保持待定。

科学判分

方程按预设模块检查依赖结构30%、函数形式40%、定量恢复30%；支持数学等价及可辨识参数组合。黑箱预测不自动获得公式恢复分，竞争解释未排除时不声称唯一机制。正式新评分用于新冻结批次；旧提交可另作明确标注的事后补充评审，旧成绩不折算、不覆盖。

多环境路线

环境重点
三菌条件作用、资源通量与联合调节，随后新准备和干预迁移
耦合振子未知连接与系数组合、切边与组合加载；公开公式不计发现
其他环境按科学差异和可辨识性选择；电阻抗接受内部结构等价类

运行与评测环境

公开任务包→考生沙箱↔可信实验室→封存提交→无网络预测沙箱→可信数值评测与独立科学judge。隐藏实例和目标仅在可信侧；预测执行器只得到查询。镜像、源码、预算和评分合同事前冻结，失败记录保留。

执行里程碑

  1. 保存三层与过程合同，重组文档导航。
  2. 接入三菌与振子标准任务包及双评分输出，完成必要锚点校准。
  3. 真实Linux隔离与干净预测验证。
  4. 冻结新实例和完整task，开展GPT＋Codex实测。
  5. 独立审阅并据科学缺口优化；保留失败和旧协议。

过程设计与实现进度分开发布。新目标导向控制任务必须先验证可达性，不静默添加到旧题。飞书参考正文尚未读取，本方案依据用户确认方向，待正文可访问后对齐。

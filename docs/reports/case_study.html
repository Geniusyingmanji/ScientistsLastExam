微生态（三菌株）完整案例

简介隐藏方程如何隐藏随机干扰评测构建工具 / MCP结果真实回复发现深度

1 · 简介

这是一个可干预、可采样的三菌培养舱。研究者观察 A、B、C、营养和匿名化学池，自主设计实验，提出方程与结构解释，并在观测前登记预测。

A 为 B 提供底物，B 为 C 提供底物和抑制物。除此之外，C 的摄取通量直接包含 A、B、C 的联合项：A 的数量改变 B 对 C 的有效影响。相同的 B，在不同 A 背景下可能产生不同方向的调节。

当前显式三体环境已完成一次 GPT＋Codex 实测。它是虚构的碳守恒动力学，不是对真实菌群的拟合；先前含信号记忆的实验结果保留，不与本次混算。

本页面向读者解释设计者机制，不是 agent 题面。实例参数、种子和封存目标不公开；公开机制说明不构成抗污染保证。

2 · 隐藏方程

碳池 S、A、B、C、X、N、Y、Q、W 的单位为 mmol C/L；W 是惰性残留，时间单位为小时。当前环境采用固定产物分配，在 C 通量中加入显式三体调节，不使用旧实验的隐藏记忆状态。

θ = 2^((T−30)/10)
qA = θ uA A S/(KS+S)
qB = θ uB B X/(KX+X)
qC,base = θ uC C N/(KN+N)/(1+Y/KI)
M(A,B) = 1 + B/(KB+B) · [−β + γ A/(KA+A)]
qC = qC,base · M(A,B)

三体增量 ∝ ABC / [(KA+A)(KB+B)]
             × N/(KN+N) / (1+Y/KI)

S′ = −qA
A′ = 0.35qA − θdA
B′ = 0.40qB − θdB
C′ = 0.50qC − θdC
X′ = 0.35qA − qB − θδX
N′ = 0.42qB − qC − θδN
Y′ = 0.18qB − θδY
Q′ = 0.05qA − θδQ
W′ = 0.25qA + 0.50qC + θd(A+B+C) + θδ(X+N+Y+Q)

联合调节同时影响 N 的消耗及 C/W 的生成，保持碳守恒。B 的调节方向取决于括号内的符号；A 较低时可抑制，较高时可促进。实现采用有界门函数，保证合法非负状态下通量非负。

这是有效三体作用，不等于发现唯一的微观三体过程；隐藏介质或状态依赖的有效两两描述仍可能等价。数值检查包含独立积分、非负性和碳守恒。查看动力学实现。

3 · 如何隐藏

agent 只看到 substrate、A、B、C、m1–m4、residue 九个通道及带噪实验结果。匿名池名称固定；反应公式、实例系数和封存评测目标不可读取。

允许单独培养、组合培养、补料、移除与改温。区分联合调节需要控制其他条件，比较不同 A 背景下 B 的效应；共同变化本身不是因果证据。

实验服务、算子源码和私有证据不挂载到 agent 工作区。探索共享服务网络，因此不声称完成网络对抗安全验证。最终预测进程单独隔离并禁用网络。

4 · 随机干扰

动力学本身确定性。每个通道加入标准差为 0.002 mmol C/L 的独立高斯测量误差，再截断为非负：

观测 yⱼ = max(0, xⱼ + εⱼ)，εⱼ ~ Normal(0, 0.002²)

零附近的截断会造成均值偏差。跨实例参数也有变化，但一次培养内不随机漂移。目前没有过程噪声、仪器漂移或额外杂峰；不能将未实现的干扰写成实际测评条件。

5 · 评测构建

  1. 运行前冻结实例、源码、预算、诊断面板与逐格审阅标准。
  2. agent 自选带噪实验，提出模型；测试既有预测时先登记配置、预测数组与模型哈希。
  3. 提交声明和模型哈希后关闭实验，禁止覆盖提交；再独立核验实际模型文件是否一致。
  4. 隔离执行冻结模型，分别报告预测误差、逐格发现证据及工程失败。

发现形式为规律/结构，理解维度为规律推导/机制解释/统一解释/反事实。每格评估预设科学目标的实际恢复程度，区分遗漏、错误与可辨识范围。证据用于核验，不按材料齐全程度计分；具体方法见“发现深度”。

本次为单个暴露开发实例，48次尝试、1800秒上限，4个预先确定的诊断面板。面板与自主实验的实际重叠由独立审阅检查，不能仅凭事前确定就称为未见泛化。原证据判据审阅保留作历史诊断，不作为发现程度成绩；新评分方案待校准后用于新实验。

6 · 工具 / MCP

运行 GPT-5.6-sol 与 Codex harness。agent 使用真实 MCP 工具访问实验服务，并在隔离工作区编写分析与预测程序。

工具或交付功能与约束
describe公开通道、单位、合法字段、噪声与预算，不返回隐藏方程。
experiment每次新培养。A/B/C初值0–1，营养0–5，其余池0–2；温度20–40°C；1–25个递增采样点，最长48小时。
events最多8个有序事件，允许改温、添加或按比例移除。添加每次最多2、总量最多8；事件不能晚于末次采样。同一时刻先操作后采样。
register_prediction观测前绑定实验ID、配置、预测与模型哈希；禁止追认与覆盖，不返回隐藏反馈。
submit_matrix封存最终声明及证据审计，关闭实验；哈希还需独立核对实际文件。
分析与提交report.md：方程、单位、证据与限制；claims.json：逐格声明、范围、竞争解释及实验编号；model.py：predict(spec) 返回时间×九通道预测。

合法实验示例

{"initial":{"A":0.1,"B":0.2,"C":0.2,"substrate":2},
 "times":[0,2,6,12,24],"temperature":30,
 "events":[{"time":6,"channel":"m4","remove":0.8}]}

spec 仅允许 initial、times、temperature、events；额外标签字段不合法。48次上限包含无效尝试。所有未采样的准备阶段仍执行。最终预测检查使用只读冻结文件并禁用网络。

8 · 真实回复

以下为本次最终报告中的可见文字，不是内部思考：

Claims concern effective observable dependencies/carbon flow, not molecular identities.

即：声明涉及可观测的有效依赖和碳流，不涉及分子身份。报告提交了三个资源摄取通量、产物分配与周转方程；冻结程序的 C 摄取式仅包含 C 和底物项，没有显式 A/B 联合调节项。

这描述的是候选实际提交内容，不是审阅通过的发现结论。方程适用范围、前瞻证据和遗漏机制正在独立核验。

9 · 发现深度

评价实际恢复了多少科学内容。证据完整性是核验条件，不是发现程度。原先按证据判据数量累计的0–3分不再用于表示发现深度。下述为拟采用、待基线校准的评分方案，尚未产生正式新分数，也不覆盖旧实验成绩。

方程按独立动力学模块评估

模块与可辨识范围在实验前固定；未提交的模块仍在分母内，不能通过缩小声明范围获得满分。拆写方程不增加模块数量。

模块需要恢复的科学内容
A摄取A、营养、温度的依赖及营养饱和形式
B摄取B、底物、温度的依赖及底物饱和形式
C基础摄取C与底物的依赖及抑制作用
A–B–C联合调节A如何改变B对C的影响，包括方向翻转、饱和与交互
产物分配摄取通量如何转化为菌体、代谢物和残留
周转与守恒衰减项、去向及各状态方程之间的碳流一致性

每个模块如何评分

评分方面建议权重实际核验
依赖结构30%正确变量、作用方向与交互关系；遗漏必要项、引入错误作用分别记录并扣分。
函数形式40%线性、饱和、抑制或交互门控；检查极限、斜率、曲率和条件变化。允许数学等价表达。
定量恢复30%固定提交参数，在封存状态与干预条件上比较通量或变化率，禁止用评测目标重新拟合。

以上权重是设计建议，须先用参考解、经验基线、遗漏项模型和错误模型检验，再冻结权重、阈值、模块分母与聚合规则。当前不能据此回填一个看似精确的总分。

真实动力学：dx/dt = f(x,u)
候选动力学：dx/dt = f̂(x,u)
模块归一化误差：Eₖ = √{ (1/N) Σᵢ [(f̂ₖ(xᵢ,uᵢ) − fₖ(xᵢ,uᵢ))/sₖ]² }

sₖ是实验前固定的物理尺度。评测状态覆盖低值、高值、饱和区和干预条件；零通量区与活跃区分开，避免大量容易的零值稀释误差。通量仅在可辨识时独立计分，否则比较可辨识的状态变化率组合。长期轨迹RMSE另报，用于检查误差积累，不替代方程恢复。

三体项的具体判别测试

qC = qC,base · {1 + B/(KB+B) · [−β + γA/(KA+A)]}

IAB = qC(A高,B高) − qC(A低,B高)
    − qC(A高,B低) + qC(A低,B低)

固定C、底物、抑制物和温度，正交改变A与B，分别检查A效应、随A变化的B效应、交互差分IAB，以及多个浓度下的饱和与方向翻转。不能只用四个点证明完整函数形式，温度变化须另设正交条件。

当前冻结模型的C摄取式没有A/B联合调节，因而预测这一通量的A/B交互为零。低密度轨迹拟合好不能抵消该关键模块的遗漏；摄取、分配等其他模块仍可分别获得部分恢复评价。当前诊断未完成上述完整正交设计，不能把现有结果当作新方案的正式评分。

等价、近似与不可辨识

  • 代数变形、变量替换和可辨识参数组合按数学等价性核验，不做字符串匹配。
  • 只有“A促进C”这样的定性判断，不能等同于恢复完整定量公式。
  • 不同函数在有限范围近似正确，可获得相应范围的部分恢复评价，不能据此认定全域形式正确。
  • 黑箱程序可以获得预测成绩；未给出可核验的方程，不自动获得方程形式分。
  • 不可分别辨识的参数只评可辨识组合；有效作用结构不等于唯一微观实现。

形式规律推导机制解释统一解释反事实
规律恢复哪些定量关系，能推导多大范围的观测恢复哪些耦合项、通量与作用机制同一方程跨背景成立到何种程度，遗漏哪些调节未观测干预下效应的方向、大小与范围恢复程度

每格围绕预设科学目标区分未发现、定性发现、部分定量恢复、完整定量恢复并通过区分性检验；不是每满足一条材料要求就加一分。具体数值映射仍待校准，不把各格重复相加。最终同时展示模块覆盖、关键遗漏、失效条件与预测误差；证据不足的结论标为未确认，不伪装成已发现。

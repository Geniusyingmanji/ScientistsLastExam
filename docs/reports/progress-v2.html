二、三个核心问题：当前证据

问题已观察到的现象下一步
科学能力还是工程失败？最后一个GPT任务先后出现API断连、提交数组格式错误，最终成功得到99.33。这些失败不能当作科学困难。保留失败类别；将格式预检与科学推断指标分开，新协议不回改旧成绩。
高分是否代表深层发现？预测与声明分明显分离。部分轨迹能准确预测，却只检验直接响应；局部效应通过也可能伴随较弱外推。要求竞争解释与前瞻区分实验，保留两者都错或证据不足的结果。
新环境应该难在哪里？普通观测下不同机制可完全重合；改变实验时机、标记关联或分组方式才可能区分。逐候选验证合法控制、可辨识范围与预算内参考可解性，避免仅靠低分认定高难度。

现有结果语义审阅为独立上下文、同模型家族的暂定结论；不将数值核验等同于机制认证。

已定义任务／未注册原型

自适应信号：新刺激历史外推

任务简介

改变刺激的强弱和时序，建立预测模型，再预测尚未测量的新刺激历史。

预埋规律

系统内部可用两种不同的调节结构实现适应：一条路径逐渐抵消输入，或通过反馈调节。特定参数关系下，两者对所有普通刺激历史都可给出相同输出。

如何藏起来

只公开刺激操作、辅助状态重置操作和一个报告读数；不提供内部状态、结构或参数。换刺激波形本身未必增加机制辨识信息。

可做实验 / 工具接口

刺激幅度0–2，最多4段，时间0–12；可测正负报告偏差。读数加入标准差0.002的独立噪声。

干扰项与辨识边界

新历史预测准确不等于结构正确。只凭普通刺激无法区分等价机制时，应允许结论为证据不足。

冻结预测程序后，对未观测刺激历史计算预测误差；单列适用范围与失败条件。机制名称不计分。

已定义任务／未注册原型

自适应信号：选择性重置辨识

任务简介

找到能区分两个既有解释的重置时机，并在观测前写下各自预测。

预埋规律

普通刺激下等价的内部结构，对辅助状态重置可以产生不同响应。重置发生在瞬态期还是适应后，会影响区分能力。

如何藏起来

重置只改变一个不可直接测量的辅助状态，报告量不被直接赋值；Agent必须由重置前后响应推断作用。

可做实验 / 工具接口

可控制reset_at与retained_fraction；保留比例1表示不干预。公开重置顺序和读数时间语义，不公开内部机制。

干扰项与辨识边界

太晚干预可能几乎无效。初版开发实验分离不足，修改时机后的结果属于已曝光设计，不能称为前瞻发现。

模型结果

GPT-5.6：未评测；DeepSeek：未评测。没有模型分数。

已有本地验证

与上一任务共用自适应信号环境的本地验证；没有额外任务级模型结果。

评分标准与当前状态

两套解释先满足来源观测，再冻结对重置实验的预测和容差；使用新观测判定支持、反驳或不确定，允许两者同时被反驳。

已定义任务／未注册原型

记忆输运：暂停后的回收

任务简介

比较累计流量相同、暂停时长不同的实验，研究回收是否只由总流量决定。

预埋规律

一类内部机制让示踪物在可流动区与滞留区之间交换；另一类让示踪物沿快慢两条独立路径移动。固定流速下可有完全相同的回收曲线；停止流动时前者仍可能重新分配。

如何藏起来

只能观察总回收比例，看不到内部区室、路径及分配。固定流速曲线可能误导Agent采用无法外推的等价解释。

可做实验 / 工具接口

每次重新注入单位示踪物，流速0–3且非负，最多4段；0表示暂停。无法反向流动或直接测内部浓度。

干扰项与辨识边界

暂停不是额外注入；噪声可使读数略超出0–1，但干净模拟守恒。小差异可能低于可辨识水平。

模型结果

GPT-5.6：未评测；DeepSeek：未评测。没有模型分数。

已有本地验证

3个曝光实例作者参考平均归一化RMSE为0.00041，经验插值0.05293；仅为环境级可解性验证。

评分标准与当前状态

预先匹配累计流量，冻结暂停前后差值及区间，再用独立重复观测检验；区间校准与机制解释分开报告。

已定义任务／未注册原型

记忆输运：预测的适用边界

任务简介

把稳态操作下拟合的预测器用于不同流速历史，寻找可复现的失效条件。

预埋规律

内部滞留与交换引入历史依赖。稳态数据拟合很好，并不保证模型能预测暂停与恢复后的过程。

如何藏起来

测试历史的观测在冻结预测器之后才获取。Agent不知道内部储存量，必须主动选择能暴露失效的历史。

可做实验 / 工具接口

沿用输运接口，允许不同非负流速和暂停时长，输出随时间变化的回收比例。

干扰项与辨识边界

有限网格的合格或失效点不能证明连续边界；临界误差附近应标为不确定。

模型结果

GPT-5.6：未评测；DeepSeek：未评测。没有模型分数。

已有本地验证

共用输运原型验证，尚无任务级模型成绩。

评分标准与当前状态

预先声明有限测试网格、误差容差和不确定性规则，再分别标记适用、失效或不确定；不得观察结果后调整容差。

研究任务草案／未注册原型

同位素配对：配方与追踪

任务简介

在总标记量相同的情况下改变两个位置的联合标记配方，再预测单标记和双标记产物随时间的变化。

预埋规律

模型内部在“保留源分子配对”与“两个位置独立重新组合”之间混合，并有固定周转速率。两种解释保存相同平均标记数，但关联配方可产生不同双标记比例。

如何藏起来

只给输入配方与产物零、单、双标记比例；不告诉重组比例和周转速率，也不能分辨单标记产物的具体位置。

可做实验 / 工具接口

输入按00、10、01、11排列的四个比例，总和为1；最多4次配方段，可切换未标记配方做追踪。每次重置为未标记产物。

干扰项与辨识边界

若源配方两个位置本来独立，竞争解释可能不可区分。测量噪声使三种产物读数之和未必恰好为1。

模型结果

GPT-5.6：未评测；DeepSeek：未评测。没有模型分数。

已有本地验证

3个曝光开发实例，每例4次带噪训练与6次验证。平均RMSE：无观测0.380993、经验插值0.134924、已知方程族作者参考0.000158；5项原型测试通过。

评分标准与当前状态

建议分别检查新配方/追踪预测误差、冻结的双标记对比区间，以及是否设计了能区分相同平均标记量解释的实验。尚未接入正式评分。

研究问题草案／仅候选验证程序

谱系记忆：共同祖先还是共同条件

任务简介

通过交叉配对，检验两组后代相似究竟来自共同祖先，还是来自共同培养批次。

预埋规律

合成程序中，祖先状态和培养批次状态都可以改变存活概率。两组既同祖先又同批次时，两个来源可能造成相同相关性；交叉拆分共享因素后可以区分贡献。

如何藏起来

完整候选接口尚未实现。设计意图是只公开分组操作和抽样存活比例，不公开潜在状态与效应参数；当前代码为操作者验证程序，不能当作Agent接口。

可做实验 / 工具接口

计划控制共同祖先、共同培养批次、休息时长、每组个体数及重复对数。目前仅实现共同因素的抽样核；休息历史尚未形成完整World操作。

干扰项与辨识边界

有限抽样会掩盖小相关性；共同条件是机制混淆。相关性持续不证明遗传机制，有限休息时间也不证明永久记忆。

模型结果

GPT-5.6：未评测；DeepSeek：未评测。没有模型分数。

已有本地验证

4项候选测试通过，包括解析极限、固定抽样和交叉分组检查。尚无完整World、参考拟合成绩或模型评测。

评分标准与当前状态

拟议检查四种交叉分组的协方差预测及置信区间，并按实际模拟个体数/重复数计费。正式评分、可承受预算和准入阈值均未冻结。

更新：新条件不等于结构外推

同位素原有验证主要使用新静态配方和训练中已出现类型的追踪历史，其误差不能证明新结构外推。现已补充三类独立的公开开发设计：新配方、三段新历史、不可区分负对照。两项设计检查通过，尚未进行新的模型运行或校准。

这些公开设计不是封存评测。旧开发RMSE还包含已知初始状态；后续正式评分应排除这些格子，但不回改历史结果。

同位素评分准备：先排除已知答案

新增公开提交检查：初始时刻不计入预测格子；完全相同历史、只在读数时刻或之后改变输入的对比不作为有效效应；通道与数组形状明确校验。三项检查通过。暂未接入共享评分，未修改历史成绩。

检查通过只表示形式上可检验，不保证效应非零、机制新颖或区间正确。三个比例的守恒关系也不能当作独立科学发现。下一步完善证据适配与统一校验，仍未注册为正式环境。

证据入口：双模型补齐数据 · 补跑审阅摘要 · 同位素开发汇总。公开报告不包含私有参数、封存目标或原始轨迹。

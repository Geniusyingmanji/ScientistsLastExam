微生态（三菌株）完整案例

简介强受限案例L3 新发现隐藏方程如何隐藏随机干扰评测构建工具 / MCP结果真实回复科研成果与历史评审

1 · 简介

这是一个可干预、可采样的三菌培养舱。研究者观察 A、B、C、营养和匿名化学池，自主设计实验，提出方程与结构解释，并在观测前登记预测。

A 为 B 提供底物，B 为 C 提供底物和抑制物。除此之外，C 的摄取通量直接包含 A、B、C 的联合项：A 的数量改变 B 对 C 的有效影响。相同的 B，在不同 A 背景下可能产生不同方向的调节。

当前显式三体环境已完成一次 GPT＋Codex 实测。它是虚构的碳守恒动力学，不是对真实菌群的拟合；先前含信号记忆的实验结果保留，不与本次混算。

本页面向读者解释设计者机制，不是 agent 题面。实例参数、种子和封存目标不公开；公开机制说明不构成抗污染保证。

具体案例 · 信息强受限下的群落情境发现

后续任务设计示例，尚未实现或实测。以下配额、参照资料和验证路线用于说明如何构造任务。研究路线、竞争解释及结论示例仅供读者理解设计，不随 Query 发给 agent。

研究者面对同一组三菌培养物，需要自主研究其变化并提交报告和模型。这个案例将“能否看清系统”与“能否形成新认识”分开：仪器限制证据获取，科研成果仍按同一套三个维度评价。

信息强受限，具体限制什么？

研究条件现有三菌接口拟议强受限变体
常规检测每次返回九个通道。每次只返回 substrate、A、B、C；m1–m4 与 residue 通常不可见。
扩展检测全通道观测没有额外配额。48 次尝试中最多 8 次可申请全九通道检测；这 8 次包含在总预算内，不增加实验次数。它扩充通道，不降低测量噪声。
时间分辨率每次最多 25 个采样时刻。两种检测模式每次均最多 3 个自选时刻，范围仍为 0–48 小时；只能得到浓度读数，不能直接读取通量或导数。
干预能力允许合法初始组成、改温及各通道添加或移除。保留合法初始组成设置、改温和 substrate 补加；培养过程中其他定向添加或移除暂不开放。
共同条件同一固定底层实例，每次新建培养；48 次实验尝试、1800 秒上限，无效请求也计入尝试。沿用现有带噪读数规则。比较各信息档位时，研究范围、背景资料与提示保持一致。

例如，A 的两个水平与 B 的两个水平构成四组培养，若每组各做两次全通道检测，就会用尽 8 次扩展配额。研究者需要决定把有限检测用于探索、排除混淆还是独立确认。常规读数仍允许研究群体响应，但看不到化学池时，很难判断变化来自直接调节、间接供养还是抑制物积累。

“3 个时刻、8 次扩展检测”是候选配置，需先检验区分实验的统计功效；目前不能断言这些配额足够，或已构成高难任务。正式接入时须在 describe 中公开检测模式、配额及返回通道，并对齐模型预测接口。下方现有 Query 与历史运行仍使用原九通道协议。

L3 新发现：从固定互作到群落情境规律

拟议参照知识：构建一份事前冻结的培养记录与参考模型，覆盖单菌培养和较窄的 A 初始组成范围。参考模型把 B 对 C 的额外作用表示为不随 A 改变的固定效应。这份资料包尚待构建和检验；若提供给研究者，三个信息档位使用同一份，只作为已有认识，不暗示它一定错误或一定存在新机制。

候选解释如何解释 C 的变化为何有限观测难区分
H0：固定效应B 的额外作用系数不随 A 改变；不同培养条件下的变化由营养和抑制物等化学池变化解释。在较窄的 A 范围内，两者可能给出接近的读数；匿名化学池通常不可见，又增加了间接作用的歧义。两种解释必须先在同一份源数据上拟合检查，不能把明显不相容的模型充作竞争对手。
H1：情境依赖除化学池变化外，B 的有效作用还随 A 改变，在部分条件下可能翻转方向。

可观察的发现线索：保持其他初始池、C 初值、温度及采样时刻一致，比较不同 A 初值下增加 B 的效果。定义 ΔB(A₀,t) = C(t | A₀,B高) − C(t | A₀,B低)。若在低 A 背景下为负、高 A 背景下为正，就得到一种待解释的情境反转现象；这里是结果示意，不是已取得的实验数据。

匹配初态后，各化学池和菌群仍会随时间变化。因此，这种终点反转本身不能证明直接三体机制。扩展检测需要帮助核查化学池变化，比较完整的竞争解释；若仍无法区分，只能报告有证据支持的有效关系与剩余歧义。

一条可能的研究路线

  1. 用常规检测定位值得研究的条件：自主改变初始配比与培养条件，寻找可重复响应，保留没有效应和不确定的结果。
  2. 把扩展检测用于关键对照：在匹配初始状态的 A/B 组合中追踪群体与匿名化学池，检查间接供养或抑制物变化能否解释观察到的差异。
  3. 提出并比较可检验关系：用相同观测比较固定效应、情境依赖及仍合理的替代解释；四个组合的差异不能单独确定完整函数形式或连续阈值。
  4. 先登记预测，再检验新条件：对未用于拟合的 A/B 水平登记预测与模型版本，再取得新观测；检验修订关系能否解释新条件并保留旧适用域表现。验证通道与配额需事前预留，不能用旧数据冒充独立确认。

这是一条供设计者检验可行性的路线，agent 不必照做。两个解释都可能被否定，预算内也可能无法区分；不要求研究者必然报告方向翻转。

同一项研究，三个成果维度分别看什么？

成果维度本案例中可成立的成果还不足以支持什么
L1 · 现象表征在明确的初始条件和时间窗内，可靠描述 B 的效应随 A 背景变化，必要时确认方向反转。一次读数差异不能确立稳定效应；反转也不自动说明其机制。
L2 · 规律建构建立同时描述群体与可测化学池的定量关系，说明哪些解释得到支持、哪些仍等价。更低的拟合误差或增加交互项，不自动证明解释正确或形成新知识。
L3 · 知识拓展相对冻结参照，证明固定效应关系的迁移边界，提出经新实验支持的情境规律，明确适用条件；若证据允许，再量化方向翻转的位置。只恢复隐藏参数、换写公式、提出未验证的机制，或只说“模型有局限”，均不足以确认这一知识增量。
若验证通过，报告中可能出现的结论：“在所研究的培养范围内，B 对 C 的有效作用取决于 A 的背景水平。加入这一条件依赖后，模型能够解释原固定效应模型无法覆盖的响应，并通过新条件检验；当前证据尚不能唯一确定其微观实现。”

这段文字是成果示意，不是模型真实回复。L2 评价关系是否成立，L3 评价相对参照新增了什么及其确认程度。仅发现并验证一个明确的适用边界，也可以构成范围有限的知识增量，无需强行宣称完整新机制。

设计者的解析例子：方向翻转条件如何表达？

从下方公开展示的模拟方程出发，固定瞬时 C、N、Y、T，且基础摄取通量为正时，B 对 C 摄取通量的局部影响由 φ(A) 的符号决定：

qC = qC,base · [1 + B/(KB+B) · φ(A)]
φ(A) = −β + γ A/(KA+A)
∂qC/∂B = qC,base · KB/(KB+B)² · φ(A)

若 γ > β > 0，且阈值位于可研究范围：
A* = β KA / (γ − β)
A < A* 时局部影响为负；A > A* 时局部影响为正。

这是方程的解析性质，不是强受限观测已经恢复的结论。A 指瞬时浓度；实验通常控制的是初值 A₀，不能直接把 A* 当作任意培养终点的初始配比阈值。观测得到的净生长或终点差分需结合动态模型解释；没有独立通量证据时，不声称唯一恢复内部通量或分子机制。

发现范围：本例展示相对任务参照的受控知识拓展，不声称发现人类未知的生物规律。三菌与化学通道固定，也不支持“创造新物质”的结论；新对象发现需要另有构造与验证接口的环境。

2 · 隐藏方程

碳池 S、A、B、C、X、N、Y、Q、W 的单位为 mmol C/L；W 是惰性残留，时间单位为小时。当前环境采用固定产物分配，在 C 通量中加入显式三体调节，不使用旧实验的隐藏记忆状态。

θ = 2^((T−30)/10)
qA = θ uA A S/(KS+S)
qB = θ uB B X/(KX+X)
qC,base = θ uC C N/(KN+N)/(1+Y/KI)
M(A,B) = 1 + B/(KB+B) · [−β + γ A/(KA+A)]
qC = qC,base · M(A,B)

三体增量 ∝ ABC / [(KA+A)(KB+B)]
             × N/(KN+N) / (1+Y/KI)

S′ = −qA
A′ = 0.35qA − θdA
B′ = 0.40qB − θdB
C′ = 0.50qC − θdC
X′ = 0.35qA − qB − θδX
N′ = 0.42qB − qC − θδN
Y′ = 0.18qB − θδY
Q′ = 0.05qA − θδQ
W′ = 0.25qA + 0.50qC + θd(A+B+C) + θδ(X+N+Y+Q)

联合调节同时影响 N 的消耗及 C/W 的生成，保持碳守恒。B 的调节方向取决于括号内的符号；A 较低时可抑制，较高时可促进。实现采用有界门函数，保证合法非负状态下通量非负。

这是有效三体作用，不等于发现唯一的微观三体过程；隐藏介质或状态依赖的有效两两描述仍可能等价。数值检查包含独立积分、非负性和碳守恒。查看动力学实现。

3 · 如何隐藏

agent 只看到 substrate、A、B、C、m1–m4、residue 九个通道及带噪实验结果。匿名池名称固定；反应公式、实例系数和封存评测目标不可读取。

允许单独培养、组合培养、补料、移除与改温。区分联合调节需要控制其他条件，比较不同 A 背景下 B 的效应；共同变化本身不是因果证据。

实验服务、算子源码和私有证据不挂载到 agent 工作区。探索共享服务网络，因此不声称完成网络对抗安全验证。最终预测进程单独隔离并禁用网络。

4 · 随机干扰

动力学本身确定性。每个通道加入标准差为 0.002 mmol C/L 的独立高斯测量误差，再截断为非负：

观测 yⱼ = max(0, xⱼ + εⱼ)，εⱼ ~ Normal(0, 0.002²)

零附近的截断会造成均值偏差。跨实例参数也有变化，但一次培养内不随机漂移。目前没有过程噪声、仪器漂移或额外杂峰；不能将未实现的干扰写成实际测评条件。

5 · 评测构建

  1. 运行前冻结实例、源码、预算、诊断面板与逐格审阅标准。
  2. agent 自选带噪实验，提出模型；测试既有预测时先登记配置、预测数组与模型哈希。
  3. 提交声明和模型哈希后关闭实验，禁止覆盖提交；再独立核验实际模型文件是否一致。
  4. 隔离执行冻结模型，分别报告预测误差、逐格发现证据及工程失败。

后续框架采用现象表征、规律建构、知识拓展三个成果维度。预测、干预与设计贯穿验证，探索过程独立评价。新颖性须相对于冻结的参考知识核验，旧应用成绩不转为知识拓展成绩；具体说明见科研成果与历史评审。

本次为单个暴露开发实例，48次尝试、1800秒上限，4个预先确定的诊断面板。面板与自主实验的实际重叠由独立审阅检查，不能仅凭事前确定就称为未见泛化。原证据判据审阅保留作历史诊断，不作为发现程度成绩；新评分方案待校准后用于新实验。

6 · 工具 / MCP

三菌案例 Query

这是按通用模板填写的后续新任务题面草案，默认无额外科研提示。它只提供研究范围、仪器和交付要求；本页其他栏目中的设计者方程与评分目标不随 Query 发给 agent。下方历史成绩来自原题面，尚未采用这份草案。

查看完整研究任务输入
你是一名研究者，将通过实验接口研究一个未知的三菌培养系统。

【研究背景】
系统包含三种微生物群体 A、B、C，以及可测量的营养、匿名化学组分和残留池。你可以制备培养物、调整培养条件、施加合法干预，并测量时间序列。组分名称不预先说明其生物学作用。

【研究任务】
请研究：在仪器允许的范围内，这个系统如何随时间变化，可控条件如何影响其行为？
请自主设计实验开展研究，并建立能够预测不同培养条件下系统变化的模型。具体研究问题和研究路线由你决定。

【已知信息与实验环境】
先调用 describe 获取完整仪器说明。公开观测通道依次为 substrate、A、B、C、m1、m2、m3、m4、residue，浓度单位为 mmol C/L，时间单位为小时，温度单位为摄氏度。
实验接口提供初始组成、采样时刻、温度及合法事件设置；字段、范围、事件副作用和噪声以本任务冻结的 describe 契约为准。观测含测量噪声，不能把单次读数视为无误差真值。
每次 experiment 新建培养，同一次研究的底层世界实例保持固定；改变初始组成不会重新抽取机制。初始观测需自行采集。除仪器说明外，不提供反应方程、作用关系或函数形式。

【资源限制】
最多 48 次实验尝试，无效实验请求也计入预算；运行上限为 1800 秒。
使用提供的实验工具和隔离分析工作区。可以用工作区已有的 Python 与数值工具分析自己的观测；不访问互联网或实验室私有文件。

【研究成果】
在 output/ 提交研究报告 report.md 和模型 model.py。报告形式自定，说明你的研究结论及其依据；未能确定的内容可以如实保留。

【提交说明】
model.py 提供 predict(spec)，接收合法 experiment 配置，按给定 times 返回“时间点数 × 9”的有限数值数组，列顺序与公开通道一致。模型所需状态一并提交，并能在提供的分析环境中独立运行。spec 的 initial、times、temperature、events 字段规则见 describe。
预测登记和最终提交方式见随附工具说明；最终提交后文件不再修改。

交付结构见整体 Plan 的输出说明。新题面只要求自由报告和可运行模型，不要求填写科学主张分类表；评分维度与权重仅供评测侧使用。运行前还需将自由报告提交接口与统一 runner 对齐并冻结；这里的文档更新不表示已经启动新协议实测。

既有实测接口（历史协议）

以下记录历史运行使用的接口和交付要求；上方新题面的自由报告方案尚未接入。历史运行采用 GPT-5.6-sol 与 Codex harness，agent 使用真实 MCP 工具访问实验服务，并在隔离工作区编写分析与预测程序。

工具或交付功能与约束
describe公开通道、单位、合法字段、噪声与预算，不返回隐藏方程。

8 · 真实回复

候选动力学：dx/dt = f̂(x,u)
模块归一化误差：Eₖ = √{ (1/N) Σᵢ [(f̂ₖ(xᵢ,uᵢ) − fₖ(xᵢ,uᵢ))/sₖ]² }

sₖ是实验前固定的物理尺度。评测状态覆盖低值、高值、饱和区和干预条件；零通量区与活跃区分开，避免大量容易的零值稀释误差。通量仅在可辨识时独立计分，否则比较可辨识的状态变化率组合。长期轨迹RMSE另报，用于检查误差积累，不替代方程恢复。

三体项的具体判别测试

qC = qC,base · {1 + B/(KB+B) · [−β + γA/(KA+A)]}

IAB = qC(A高,B高) − qC(A低,B高)
    − qC(A高,B低) + qC(A低,B低)

固定C、底物、抑制物和温度，正交改变A与B，分别检查A效应、随A变化的B效应、交互差分IAB，以及多个浓度下的饱和与方向翻转。不能只用四个点证明完整函数形式，温度变化须另设正交条件。

当前冻结模型的C摄取式没有A/B联合调节，因而预测这一通量的A/B交互为零。低密度轨迹拟合好不能抵消该关键模块的遗漏；摄取、分配等其他模块仍可分别获得部分恢复评价。当前诊断未完成上述完整正交设计，不能把现有结果当作新方案的正式评分。
